## 1. ⛔ 기존 novelty 기각 — Pan 2014 / Won 2016

### Pan et al., IEEE TNS 61(3), 2014 — 우리 가설 그 자체가 출판돼 있음

원문 인용:
> *"We can **assume that the whole delay chain expands or shrinks** with variation of
> temperature but **each bin contributes the same ratio** to the whole delay chain.
> **To verify this assumption**, LUTs under different temperatures are calibrated..."*

식 (6)으로 임의 온도 LUT를 상온 LUT에서 유도하고, 대부분 bin에서 오차 ~3 ps 이내로
검증(Fig. 5, Cyclone II). **전용 캐리체인 + tap/tap_d**를 클럭 주기 눈금자로 써서
온칩·무 dead-time으로 구현까지 완료.

| 우리가 하려던 것 (구 §2.1/§2.2) | Pan 2014 |
|---|---|
| 형상 불변 가설 정식화 | ✅ 명시적 가정 |
| 온도별 code density 검증 | ✅ 온도별 LUT 교정·차이 분석 |
| 스칼라 K(T)로 LUT 스케일 | ✅ 식 (6) |
| 외부 센서 없는 온칩 배율 측정 | ✅ 전용 캐리체인 |

→ 차이는 **배율 센서뿐**(그들: 전용 캐리체인 / 우리 계획: RO). **원리 동일 → 신규성 없음.**

### Won et al., IEEE TBCAS 10(1), 2016 — 형상 불변의 '관찰'도 선행

> *"the **bin-width tendency was almost unchanged**... regardless of the temperature"*
> (10→50 °C). 단 활용하지 않고 **전체 LUT를 prefix adder로 실시간 재계산**.
> 실시간교정 11.03 ps-RMS 유지 vs 미적용 43.83 ps-RMS.

추가 판정:
- **"dual-phase" 용어 충돌** — Won은 병렬 TDL 2개 + duty cycle estimator(클럭 스큐),
  우리는 0°/180° coarse 카운터(메타스테빌리티). **메커니즘은 다르나 개명 필요**
  (예: dual-edge coarse timestamping)
- Won은 960-bin을 6개 클럭영역에 걸쳐 스큐를 정량화 → 우리 "clock region 무영향"
  주장은 **"단일 영역 내 배치 시 무영향"** 으로 축소해야 함

### 기타 온도 축 선행
Mao(Sensors 2022, 구조적 저온도계수 0.014 ps/°C), Alshehry(Sensors 2023, −75~80 °C
특성화), Song(Sensors 2020, 체인 양끝 레지스터로 지연 감시).

## 3. ★ 신규 차별화 후보 2건

### 후보 ① — Shape–Scale 분리 융합 교정 (로드맵 §2.4)

$$\text{LUT} = \underbrace{\text{shape}_{RO}}_{\text{백그라운드 연속}} \times \underbrace{\text{scale}_{DPS}}_{\text{2.8초 재앵커}}$$

**근거는 우리 T1 실측**(2026-07-23, 동일 빌드 4캡처):

| 조합 | AFTER DNL/INL [LSB] | 해석 |
|---|---|---|
| RO→RO | **0.06 / 0.11** | RO는 형상 측정에 탁월 |
| DPS→DPS | 0.42 / 0.35 | DPS 이산스텝(17.857 ps ≈ LSB)이 density에 부적합 |
| 교차 | 1.94~2.91 / 3.16~3.72 | **단일 자극 편향 실증** |

*"왜 자극을 두 개 쓰나?"* → **"하나만 쓰면 편향된다는 걸 우리가 측정으로 보였다."**
(Tontini 2018의 "두 방법 일치"는 계측기 1 ps 스텝 조건 — 스텝≈LSB이면 깨짐을 실증)

### 후보 ② — 자가 검증(Self-Validating) TDC 플랫폼 (로드맵 §2.5)

기존 연구는 검증에 외부 계측기 필수(Tontini: Keysight 81150A / Won: CAEN N108A /
Korkan: AFG3101C+53230A / Carra: 외부 랜덤 펄스). 본 설계는 **온칩 자극 2종 + 참
시간 기준 + 히스토그램 엔진 + 모니터(RO·XADC)** 로 교정 생성·교차검증·불확도
보고까지 칩 안에서 완결 → 리뷰 공백 2·3에 직접 대응.

**포지셔닝:** ①이 기여, ②가 그 실현·검증 수단.

## 4. 기술 검토 (구현 판단)

### 4-1. IDELAY 체인 — 종속 연결은 가능하나 무의미

- `IDELAYE2`의 `DATAIN` 포트로 fabric에서 받을 수 있어 **종속 연결 자체는 가능**
- 그러나 중간 fabric 라우팅이 **수백 ps~ns**로 탭(78 ps)을 압도 → 균일성 파괴
- 최대 31탭 × 78 ps ≈ **2.4 ns** (5 ns 주기 미달), I/O 타일 전용, `ODELAYE2`는
  HP 뱅크 전용이라 Zynq-7020(HR)에서 사용 불가
- **실제 용법은 병렬 오프셋**(BM@N 논문: 4채널 0/100/200/300 ps)

**→ 딜레이라인 대체는 기각. 다만 `IDELAYCTRL`이 탭 크기를 연속 보정한다는 점에서
"온도 안정 눈금자" 가능성은 남음** → 별도 프로젝트로 분리(§6).

### 4-2. CARRY4 S/C 출력 검증 — 현재 구조에서 가능

**하드웨어 확인(Vivado 스키매틱):** FF 입력 MUX의 선택지가
`XOR(=O) / O6 / O5 / F8 / CY(=CO) / BX` 로 확인됨.

> **`carry_o` → `carry_co` 변경은 배선 신설이 아니라 MUX 선택만 바꾸는 것.**
> FF의 BEL/LOC·슬라이스·XDC 모두 그대로 → 테스트 위험이 매우 낮음.

**단, 신규성은 없음:** Won & Lee TIM 2016 원문 39행
> *"only four of the total eight carry element outputs (i.e., four Ss and four Cs) can be
> **directly routed to the flip-flops in the same CLB**"*

45행에서 S/C 혼합을 **heterogeneous sampling**(SCSC, SCSS, SCCC)으로 명명·출판.
**8개 전부 사용은 하드웨어가 불허**(나머지 4개는 `BX` 일반 라우팅 경유 → bin 폭 열화).

→ 우리 period-4가 3.98×로 심하므로 **선형성 개선 수단으로는 채택 가치 있음**(인용 전제).

### 4-3. 부수 발견 — 딜레이라인 슬라이스에 타 로직 혼입

스키매틱에서 `u_tdc/coarse_180_sync_reg[17]` 이 `CARRY_CHAIN[62].u_ff_1` 과 **같은
슬라이스 영역**에 배치된 것을 확인. XDC가 `u_ff_0~3`(AFF~DFF)만 고정하고 5FF 자리를
비워둔 결과.

- 라우팅 혼잡·슬라이스 내 스위칭 노이즈로 **entry transient/period-4에 기여 가능성**
- 전례: `led[2]` 부하 하나로 entry transient가 측정 가능하게 악화된 바 있음
- **점검 방법:** X42 컬럼에 `PROHIBIT`/pblock으로 타 로직 배치 금지 후 DNL 비교
- **온도 실험 종료 후** 처리(현재 재빌드 금지)
